## 4. 为什么此处停止付费，而不继续堆实现

条件上限86%不是在替78%成绩开脱：它只在“严格遵守当前契约、当前冻结库与旧单轮评分”三个前提下成立，未经独立复核不用于改判验收。现有模型错误、超时和未知用量仍保留。没有外部裁决，改Gold、改默认口径或降低门槛都不能生成可比的验收结论；再补一个近似规则也不会解除这个矛盾。

数据流核对例子：原eval启动先加载题目，核对冻结清单，再检查北京时间；本次09:54检查拒绝，尚未进入`evaluateOne`，所以没有首答、重试或Token费用。拒绝类型`PEAK_HOURS`属于调用准入层，不应归因为表、字段、JOIN或业务公式错误。来源身份由JAR SHA、打包类SHA、日志时间和退出码关联；本次没有新增检索权重或排序规则。
