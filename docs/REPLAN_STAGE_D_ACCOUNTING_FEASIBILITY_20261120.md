## 现有证据能否结算四笔未知费用

不能。新4笔调用对应 T3-011、T4-018、T4-030、T4-041；共同账本绑定了 token、题号、原请求 SHA、原体文件及长度。四份 body 均为0 bytes、`responseComplete=false`、usage/cost为空。HTTP200只说明收到响应头，不代表完整响应或完整用量。

实际包装是 `LlmSqlGenerator.invoke → CostQuota.reserve → RequestBudget.startModelCall → model.call → Lease.complete/close`。超时关闭 lease 后，其 `settled` 标记阻止再次结算；重启保留 UNKNOWN。`RequestBudget` 结束后不接受新的答案观测；这与费用 lease 是否已经完成是两个机制，不能概括成“任何迟到用量都必然被 Java 丢掉”。本次缺的是完整供应商响应事实。

代理用同一个绝对父截止限制连接、发送和读取，超时就在 `finally` 关闭上游；末尾 `drain(120)` 只等处理线程退出，不会重新打开已经关闭的连接，也不会查询供应商历史。监视器 `_transition` 要求已观察 UNKNOWN 的 ID 与内容永久保留。即使未来另取得可对应原请求的外部凭证，当前也没有合法的 UNKNOWN→KNOWN 迁移入口，不能手动删 hold。

[官方余额接口](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)返回账户余额；它不能为这里四个请求提供逐笔 usage 身份。[Chat Completions 文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)描述的是当次响应中的用量。此次未发现可直接用于这四笔核销的已保存供应商逐笔凭证或公开查询入口；这不等于证明供应商客服永远无法提供凭证。本次未登录账户、未读取 Key、未调用余额或模型接口。

## 真实接入仍缺什么

这不是生产工程准入，不能将实验子类直接放进付费控制器：

1. **分别限制写和读**。实验复用了原 socket 的单一 timeout；虽然发送前检查父截止，连接/TLS/sendall内部阻塞仍可能使用延长后的截止。真实实现必须让DNS后准入、连接、TLS、每次写操作都受原15秒父截止；只有已经发送成功后的读取允许额外账务时间。
2. **答案绝不回填**。Java真实15秒HTTP原答、status、SQL、timings及usage快照必须先封存。迟到正文仅作为共同账务证据，不交给模型SDK、评分器、纠错器或会话。实验中一直等待的直接代理客户端在0.55秒才收到504，不能拿它证明HTTP15秒上界；真正上界必须由Java入口集成另验。
3. **保留双层身份**。共同 token/题号/attempt/body SHA绑定原fence；候选 hold/requestId/callNumber/prompt SHA仍按原字节保留。共同层拿到完整原始usage可以成为KNOWN，候选已经UNKNOWN的hold仍占¥0.10，不释放、不伪造候选完成；两层差异需要单列。晚到after不得借下一题的身份结算。
4. **整轮与高峰边界**。原每题开始检查1620秒、末尾drain120秒，不自动证明新的收尾仍在整轮1740秒内。需要统一绝对整轮截止与官方窗口，同时限制最后一次collect、关闭和回调；不能靠“已经发送过”读到高峰，更不能重连、重发。
5. **资源和失败**。须事前限定收集线程/连接数、原体字节和总内存，验证取消、滴流、截断、重复JSON键、回调失败、进程终止及原件落盘失败。任何不足停止，保留UNKNOWN与原答，不悄悄放宽窗口。

这些均可先做免费本机集成与独立审查。新登记、费用/次数授权、完整工程准入缺一不可；现有D修订4判决不覆盖新观察协议。

## 技术与设计导读

1. **请求例子与链路**：假设公开“查询2018年的订单数”。原15秒HTTP截止后返回REQUEST_TIMEOUT，这份答案永久保留；若同一次已发连接在稍后的受限窗口返回完整原体，额外流程只保存usage与原token，不把迟到SQL变成正确答案。候选UNKNOWN不退款，旧空响应不复活。
2. **组件与身份**：`RequestBudget`管答案和调用次数，`CostQuota.Lease`管候选保守占用，`ModelProxy`管一次实际传输，共同账本与观察链管来源和高水位。没有TopK、打分权重或业务规则修改。数学防线是已知费用＋每份未决预留＋下一次预留；任一层拒绝即停，平均成本不能覆盖身份不明的债务。
3. **数字与实际收益**：免费审计768＋1140份文件；本机8场景/9断言通过，供应商0次。证明“抑制迟到SQL”和“同一次连接后续取得费用证据”可以分开；缩尺实验尚未证明真实15秒集成、供应商回收率、完整正确率、P95或成本达标。真实Java集成另作同版留证，不用缩尺计时冒充。
4. **取舍与答辩**：不按平均费用释放UNKNOWN，不扩大模型响应预算，不换模型、关思考或改评分。“为什么超时仍占费”：本地没收到完整响应不等于供应商没生成；“为什么不让迟到SQL变成成功”：那会改变15秒业务预算和测量结果，只能追加账务旁证。
