## 判定原则

SQL执行成功、数值碰巧相同、业务口径一致、展示契约一致是四个不同结论。缺少业务约定时，不能把某一种Gold表现形式伪装成唯一正确语义；也不能修改Gold或评分去掩盖当前默认行为的代价。选择默认约定必须公开适用条件，并用其他实体、不同数据和显式覆盖证明可复用。
